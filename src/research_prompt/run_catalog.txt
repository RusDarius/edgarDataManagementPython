Output
------
  duckdb output    Default. The suite folder is the deliverable.
  queries.txt      Written in that folder: every field, its meaning, and
                   the copy-paste queries. Open it before writing SQL.
  canvas output    Add this line on the paste when you also want the page.
  data lists       Name tables on that canvas. Without it the canvas is
                   decisions plus one Ledger.
  Wisdom           Always writes wisdom-YYYYMMDD with one Ledger.
                   Name tables on that canvas only with data lists.

Quote leftover in SQL as "left". Columns stay separate. pe_fwd is the
projection next-year PE (fp_pe_y1). pe_fwd_tv stays empty. fp_pe_y5,
fp_evebitda_y1, fp_evebitda_y5, fp_net_debt_y1, and fp_fcf_y1 stay
separate. Do not fill pe_fwd with EV/Rev. Street price, pack price, and
model terminal stay three numbers.
A label is a bin. The dump always keeps the percent beside it, with or
without an agent and with or without a canvas.
  ABOVE / BELOW uses vs50 (percent versus the 50-day average). vs200 is the 200-day gap.
  DISCOUNT / PREMIUM / INLINE uses that column's percent versus the industry median.
  DISCOUNT is <= -5. PREMIUM is >= 5. INLINE is between.
  Two valuation reads stay side by side. Do not collapse them into peer.
  Trailing TV, taken as published: pe_peer beside pe_vs_ind, evebitda_peer
  beside evebitda_vs_ind, and pb_peer / evfcf_peer when those fields are on the row.
  Forward derivative, which can be off: pe_fwd_peer beside pe_fwd_vs_ind,
  evebitda_fwd_peer beside evebitda_fwd_vs_ind.
  peer / val_vs_ind is only the one multiple setup quoted. Focus tables show
  the trailing bins and the forward bins, each with its percent.
  val_ind_med is the median of that quoted field.
  val_vs_avg is the percent versus the industry average. val_ind_avg is that average.
  Do not average the two percents. Other relatives use FIELD_vs_ind and FIELD_vs_avg.
  UNUSED / MID / PAID uses rng (0-100).
queries.txt in the suite folder names these fields. A canvas table shows
the percent next to the label. Zoom handles the width.

Global commands (compile, wisdom, all, forward, analysis style) use six
datasets. The pack already puts the first four on each name. Wisdom also
writes datasets/ so the files are listed in one DuckDB. Do not rerun a
multi-hour backtest unless asked. MTP is climate. Backtest IC is not a
leftover gate.

  all-fields          trading_view_all_fields_data. History and span. Never SELECT *.
  prediction          prediction_analysis. Weeks bo / cont / fwd on the pack tape.
  edge                edge_research upside. Pack leftover is max(street PT, edge).
  market timing       market_timing_policy. On the pack row. Not a buy list.
                      action_policy_recommendations also has entry_low,
                      kill_px, thesis_drawdown_px, thesis_chase_px.
  backtest            backtests/runs/*/family_metrics.csv. Rank spearman_ic.
  value projection    finproj_* and fingrowth_*. Joined as fp_* on forward_value.

Manual lock, no rescan:
  python src/run_operator_suites.py sources
Folder: <newest briefing_pack>/datasets/  (wisdom also writes suites_*/datasets/)
