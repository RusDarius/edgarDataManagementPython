GLOBAL DATASETS
---------------
Compile, wisdom, all, forward, and analysis style use six datasets:
all-fields, prediction, edge, market timing, backtest family IC, and
value projection. The pack already carries the first four on each name.
Wisdom writes datasets/ with the file paths and family_metrics when a
backtest run is on disk. Do not rerun that backtest unless asked.
MTP is climate. Backtest IC is not a leftover gate. pe_fwd is the
projection next-year PE (fp_pe_y1, path or CAGR). pe_fwd_tv stays empty.
fp_pe_y5, fp_evebitda_y1, fp_net_debt_y1, and fp_fcf_y1 stay separate.
Do not fill pe_fwd with EV/Rev. Street, pack, and model prices stay three numbers.
A label is a bin. The percent beside it is the coverage.
  ABOVE / BELOW is tech_sma. The percent is vs50 (50-day average). vs200 is the 200-day gap.
  DISCOUNT / PREMIUM / INLINE is a bin. The percent beside it is that column's gap versus the industry median.
  DISCOUNT is <= -5. PREMIUM is >= 5. INLINE is between.
  Trailing TV, taken as published: pe_peer + pe_vs_ind, evebitda_peer + evebitda_vs_ind.
  pb_peer and evfcf_peer the same way when present.
  Forward derivative, which can be off: pe_fwd_peer + pe_fwd_vs_ind, evebitda_fwd_peer + evebitda_fwd_vs_ind.
  peer + val_vs_ind is only the one multiple setup quoted. Focus tables and canvases show both reads.
  val_ind_med is the median of that quoted field.
  val_vs_avg and val_ind_avg are the same gap versus the industry average. Different columns.
  The peer label uses the median only. Every other relative metric has the same four names:
  FIELD_vs_ind, FIELD_ind_med, FIELD_vs_avg, FIELD_ind_avg (pe, opm, left, d5, and the rest).
  UNUSED / MID / PAID is tech_rng. The position is rng (0-100).
DuckDB keeps the label and the percent as separate columns on every dump,
whether or not an agent writes a canvas. A canvas name table shows both.
Zoom handles the extra column. Do not blend them into a score.
