Move Prediction Pool Analysis — SQL Block Reference
File: move_prediction_pool_analysis.session.sql
Connection: pooled_move_prediction_runs.duckdb (move_prediction_run_pool)

HOW TO RUN (DBCode / SQLTools)
  - Click "Run block" on the line: -- @block <block_name>
  - Do NOT run explainer/section comment lines (they are not SQL).
  - Full documentation for each block lives in this file.

SCORE CONVENTIONS
  score / risk_adjusted_score: roughly -3.00 to +3.00
  directional up: score >= 0.35 | strong up: score >= 1.10
  confidence: 5-99 (high >= 70)
  direction: Strong Up, Up, Neutral, Down, Strong Down, N/A
  manager_action_signal: add_long_breakout, accumulate_value_catalyst, neutral_watch, ...

BLOCK: q_pool_profile_strongest_score_price_corr
----------------------------------------
Score-threshold correlation ladder per profile to verify actionable cutoffs.
Slices: ALL (baseline), BULLISH_UP (>=0.35), STRONG_UP (>=1.10), VERY_HIGH (>=1.50), ELITE (>=2.00), TOP_DECILE (best tickers per ISO week).
Compares each slice to ALL via *_lift_vs_all columns; adds weekly snapshot consistency (mean/median weekly corr, pct_weeks_*_aligned).
RUN: use "Run block" codelens on the @block line, or cursor on WITH below.
Requires pool_raw_scan_rows with change, Perf.W, Perf.1M, Perf.5D. Default horizon: weeks.
Min pair_count: ALL>=50, mid tiers>=20, ELITE>=10, TOP_DECILE>=15 — lower in SQL if your pool is smaller.
Key columns: score_slice, strongest_metric, strongest_corr, score_perf_w_lift_vs_all, pct_weeks_strong_aligned, null_diag_note.
NaN fix: direction_vs_perf_w_corr excluded when direction_sign is constant; non-finite corrs filtered from ranking.
