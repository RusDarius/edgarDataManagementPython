NAV = equity mark + cash. Ladders: m5/m10/m15/m20 from mark, c15 vs cost
(continuity zone), SMA50, ATR×1.5, wipe, trim 25/33/50 cash vs remaining
NAV-at-risk. Industry nav_pct. close_usd / cost USD per share (not DKK/EUR
quote). No 0–100 risk score.

Live leftover + unused range → do not cut a thesis for m5 noise.
vs_cost ≤ −15 + lost SMA50 + weak RAS = coded thesis-kill.
Paid chase (leftover gone, rng≥85, RSI≥70) → TRIM locks a win.
Mix avoid + live leftover = HOLD_NO_ADD. Polar ADD ↛ EXIT.
If vs50>0 SMA50 is stop below; if vs50<0 SMA50 is bounce above (stop ATR/c15).
Path = history/span (close, PT, ATRP, weeks scores, **and val_field** — not EV/Rev for every name).
Setup = generic_utils.setup (val_field / peer / tech_sma). Do not quote EV/Rev
when PE / EV/EBITDA / P/B is populated. Leftover opening vs dying vs cheap-and-broken.
Average down default no (print / thesis-kill / leftover gone / street cut).
ADD only leftover live + mix not avoid + cash from EXIT/TRIM, toward SMA50/ATR.
Cut-and-reenter: TRIM so remaining wipe_nav is a size you still want AND
cash can restart at SMA50/ATR without enlarging the original.
