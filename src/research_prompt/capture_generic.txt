What to produce (canvas first; chat is a short snapshot):
  1. Scan folder (`--out-dir`): `capture.duckdb` + `capture.md` + `overview.log`.
     DuckDB tables: `book_asof`, `book_names`, `exits`, `fund_path`, `fund_span`,
     `score_path`, `score_span`, `jobs`, `coverage_fill_rates`, `ic_snapshot`.
  2. Canvas `capture-YYYYMMDD.canvas.tsx` (project canvases/), one Ledger tab.
     Tabs: Guide / Book / Fundamentals / Progression / Jobs / Follow-up / Ledger.
  3. Chat: best 1-4 week / 1-2 month moves from deterministic evidence only.

Acceptance checks for the first 90-day run:
- exits include `PATH`, `TEAM`, `VEEV`, `CSCO`, `CHKP`
- fund_path for exited names still continues after holdings exit
- score_path shows `bo/cont/fwd/early/sms/recov/rev` over the window
- fill rates include `close`, `pt`, `pe`, `rsi` with `n_days`

Replay (same dump, walk-forward vs later closes):

  python src/run_operator_suites.py capture-replay --af-start 01_04_2026 --af-end 11_09_2026 --rebuild
